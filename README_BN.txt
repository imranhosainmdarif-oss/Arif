টেইলার্সের হিসাব নিকাশ — প্রাথমিক Android প্রজেক্ট

GitHub Actions দিয়ে debug APK তৈরি করার workflow যুক্ত আছে। Build সফল হলে Actions run-এর Artifacts থেকে TailorsHisab-debug-apk নামের ZIP পাওয়া যাবে; তার মধ্যে app-debug.apk থাকবে।

গুরুত্বপূর্ণ সীমাবদ্ধতা: Gmail sign-in এবং cloud database sync এখনো যোগ করা হয়নি। APK build হওয়া মানেই সব ফিচার পরীক্ষিত নয়। বাস্তব হিসাব রাখার আগে পরীক্ষা করুন।
